# Sales Intelligence Pipeline

A project where I cleaned and analyzed the Superstore dataset using Python and PostgreSQL.

## What I did
- Cleaned the raw CSV data using pandas (fixed column names, data types, dates)
- Loaded the cleaned data into a PostgreSQL database using SQLAlchemy
- Built an interactive Power BI dashboard with 3 report pages — Executive Summary, Product & Category Analysis, and Operations   Analysis — to visualize sales trends, regional performance, and product profitability.

## Files
- 02_data_cleaning.ipynb — data cleaning steps
- 03_postgresql_loading.ipynb — loading into PostgreSQL
- superstore_cleaned.csv — the cleaned dataset
- superstore.csv - raw dataset
  

## Tools used
Python, pandas, PostgreSQL, SQLAlchemy, Jupyter
